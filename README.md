# Go Core Task

Решение тестового задания по модулю Go-core.

## Структура

Каждое задание находится в отдельном каталоге `1` ... `9`. В каждом каталоге есть исходный файл и unit-тесты.

## Запуск

Запустить все тесты:

```bash
go test ./...
```

Проверка с race detector:

```bash
go test -race ./...
```

Запустить отдельную задачу:

```bash
go run ./1
go run ./2
# и т.д.
```

## Примечания

- В задаче 1 соль `go-2024` вставляется в середину `[]rune`, после чего UTF-8 представление полученной строки хэшируется SHA-256.
- В задаче 2 функции `addElements`, `copySlice` и `removeElement` возвращают независимые слайсы, чтобы изменения исходного слайса не влияли на результат.
- В задаче 5 порядок результата соответствует порядку второго входного слайса, что даёт для примера из задания `[]int{64, 3}`.
- В задаче 6 используется `context.Context`, чтобы генератор можно было корректно остановить и не оставлять goroutine после теста.
- В задаче 8 `sync.WaitGroup` не используется: синхронизация счётчика выполнена через semaphore на buffered channel.
